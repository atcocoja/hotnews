# 镜头语言速查表

## 景别

- 远景：建立空间
- 全景：展示人物与环境关系
- 中景：讲动作
- 近景：讲情绪
- 特写：讲细节与重点

## 运镜

- 推近：强化主体
- 拉远：放大空间或做收束
- 横移：展示环境或对比关系
- 跟拍：强调移动
- 环绕：突出人物或物体
- 俯冲：增强冲击感
- 抬升：用于升华或揭示

## 新闻快反常用组合

### 结果钩子

- 远景建立 -> 中景推进 -> 特写结果

### 数据解释

- 中景主体 -> 信息图融合 -> 特写数字

### 人物情绪

- 中景动作 -> 近景表情 -> 特写细节

### 对比关系

- 左右并置 -> 交替推进 -> 同框收束
