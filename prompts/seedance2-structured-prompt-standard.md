# Seedance 2.0 结构化提示词标准

这份标准融合了火山引擎官方《Doubao Seedance 2.0 系列提示词指南》和 `make-prompt-seedance2` 的高质量社区实践。

## 核心原则

- 用结构化字段，不只写一整段长描述
- 明确时间轴
- 明确镜头语言
- 明确动作节奏
- 明确参考素材分别起什么作用
- 明确声音设计

## 推荐公式

```text
【分镜声明】@图片X 是四格分镜脚本参考图（Storyboard），不是要被整体动画化的单张画面。
请将其理解为四个独立镜头的视觉参考，按照分镜一（左上格）→ 分镜二（右上格）→ 分镜三（左下格）→ 分镜四（右下格）的顺序，
依次生成四段连续镜头，严禁将四格图作为整体进行动画处理。

【风格】_____ 风格，_____ 秒，_____ 比例，_____ 氛围

【时间轴】
分镜一（左上格）0-X秒：[镜头] + [画面] + [动作]
分镜二（右上格）X-Y秒：[镜头] + [画面] + [动作]
分镜三（左下格）Y-Z秒：[镜头] + [画面] + [动作]
分镜四（右下格）Z-N秒：[镜头] + [画面] + [动作]

【声音】_____ 配乐 + _____ 音效 + _____ 对白/旁白

【参考】
@图片X 作为四格分镜顺序参考，按左上→右上→左下→右下依次呈现
@视频1 _____
@音频1 _____
```

## 新闻类视频推荐写法

### 开头

- 先给结果
- 立刻建立场景
- 第一镜就出现人物或结果对象

### 中段

- 一段只讲一个功能点
- 数据解释放在独立段落
- 每 3-4 秒有一次明确的镜头推进或信息推进

### 结尾

- 用结果升华，不要空喊口号
- 如果有对比关系，收束到最终判断

## 镜头词优先级

- 常用：推近、拉远、横移、跟拍、环绕、俯冲、抬升
- 谨慎使用：极端甩镜、故意故障、过强抽象特效

## 适合新闻快反的模板骨架

```text
【分镜声明】@图片1 是四格分镜脚本参考图（Storyboard），不是要被整体动画化的单张画面。
请将其理解为四个独立镜头的视觉参考，按照分镜一（左上格）→ 分镜二（右上格）→ 分镜三（左下格）→ 分镜四（右下格）的顺序，
依次生成四段连续镜头，严禁将四格图作为整体进行动画处理。

【风格】体育纪录片写实质感，12秒，9:16 竖屏，紧张克制

【时间轴】
分镜一（左上格）0-3秒：建立场景与事件结果
分镜二（右上格）3-6秒：推进到人物或关键对象
分镜三（左下格）6-9秒：进入核心动作或数据解释
分镜四（右下格）9-12秒：完成收束，给出余韵

【声音】鼓点推进配乐 + 现场环境声 + 必要时加入一句旁白

【参考】
@图片1 作为四格分镜顺序参考，按左上→右上→左下→右下依次呈现
@视频1 参考运镜节奏
@音频1 参考节拍和情绪
```

## 生成前检查

- 这段是否只服务一个叙事目标
- 时间轴是否清楚
- 运镜是否真实可执行
- 参考素材用途是否标明
- 是否避免了写实真人脸依赖
