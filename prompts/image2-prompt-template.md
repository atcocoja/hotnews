# Image 2 提示词写法

用于生成单段视频的宫格分镜图。

## 基本规则

- 一张宫格图只服务一段 `12-15 秒` 视频
- **不限制为四宫格，根据场景复杂度灵活选择：**
  - `2x2 四宫格`（4帧）：适合简单场景、静态对话、信息展示
  - `3x3 九宫格`（9帧）：适合复杂动作序列、多步骤过程
  - `3x4 / 4x3 十二宫格`（12帧）：适合高动态场景、密集镜头切换
- 每格必须写清：
  - 景别
  - 主体
  - 动作
  - 场景
  - 氛围
- 全图必须强调：
  - 同一主角一致性
  - 风格一致性
  - 无大段文字
  - 无水印无 logo

## 标准结构

1. 先定义整张图用途
2. 写全局风格
3. 写版式
4. 逐格描述
5. 最后写限制条件

## 通用尾句

要求：四格人物保持同一主角形象和服装连续性；镜头语言丰富；高细节；适合后续图生视频；画面不出现大段文字、字幕、水印、logo。
