# 分镜设计参考

这份参考主要吸收了飞书文档里的中文镜头语法，给热点新闻视频做分镜时优先用“选项式决策”而不是临时想词。

## 1. 景别

- 大特写：强调极限细节、伤口、按钮、数字、眼神
- 特写：强调物体重点或局部表情
- 近景：强调脸部情绪
- 中近景：适合口播、解说、轻剧情
- 中景：适合动作说明、采访、讲解
- 四分之三身景：适合人物与动作兼顾
- 全景：适合完整人物和环境关系
- 远景：适合运动、追逐、旅行、城市空间
- 大远景：适合城市、战场、宏大开场

## 2. 垂直角度

- 平视：客观、正常、最稳
- 俯视：削弱主体，适合弱势、观察感
- 仰视：强化主体，适合压迫、胜利、纪录时刻

## 3. 水平角度

- 正面：信息清楚，适合讲述
- 侧面：动作线条清晰
- 四分之三侧面：最常用，兼顾脸和动作
- 背面 / 过肩：适合带入、解释、对话

## 4. 构图

- 中心构图：结果、纪录、重要主体
- 三分法：更自然
- 前中后景层次：更有纵深
- 遮挡构图：增强临场感
- 引导线：赛道、街道、栏杆、灯光都可以作为视觉引导

## 5. 光影

- 顺光：信息最清楚
- 侧光：立体、电影感强
- 逆光：氛围强，适合结尾升华
- 顶光：压迫、戏剧化
- 体积光 / 灰尘 / 雨雾：增强空间感

## 6. 运镜

- 平移：展示环境或并行跟随
- 跟拍：适合运动主体
- 推近：强调情绪或结果
- 拉远：适合收束或暴露空间
- 环绕：适合人物/物体展示
- 抬升：适合结尾升华
- 俯冲：适合冲击镜头

## 7. 用在热点新闻里的简化决策

### 结果型新闻

- 开头：远景/全景建立 + 特写结果
- 中段：中近景解释 + 数据特写
- 结尾：拉远或抬升收束

### 人物型新闻

- 开头：中近景或近景锁定人物
- 中段：动作中景 + 表情特写
- 结尾：仰视或逆光升华

### 数据解释型新闻

- 开头：主体中景
- 中段：数据与画面融合
- 结尾：回到主体或用空间镜头做收束
