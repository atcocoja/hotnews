# NXX 生产检查清单

## 事实层

- [ ] 事件日期已写成绝对日期
- [ ] 核心数字已复核
- [ ] 争议点已标注
- [ ] 没有把未证实说法写成事实

## 脚本层

- [ ] 前 3 秒有钩子
- [ ] 单段只做一个叙事目标
- [ ] 时长控制在 120-180 秒内
- [ ] 结尾有明确收束

## Image 2 层

- [ ] 每张图只服务一段视频
- [ ] 默认四宫格
- [ ] 主角一致
- [ ] 没有大段文字/水印/logo

## Seedance 层

- [ ] 提示词包含风格/时长/比例/时间轴/声音/参考
- [ ] 每 3-4 秒有清楚画面推进
- [ ] 每段只保留一个核心动作
- [ ] 运镜不夸张失真
- [ ] 参考素材用途已写清
- [ ] 素材总数不超过 12
- [ ] `@图片1` 是否放了最重要的参考
- [ ] 角色一致性是否依赖单独角色图而不是拼图
- [ ] I2V 提示词是否足够短，避免覆盖首帧身份信息
- [ ] 如画面涉及材质、天气、建筑细节，是否考虑中英双版本 A/B 测试

## 发布层

- [ ] 标题不误导
- [ ] 封面字可读
- [ ] 标签与平台匹配
